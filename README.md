# Flask University Portal

A comprehensive web-based university portal application built with Flask, featuring role-based access, user authentication for both **students and faculty**, and SQLite database integration (`university.db`).

## 🚀 Features

- **User Authentication & Role-Based Access:** Secure login and registration for different university roles (Students and Teachers/Faculty).
- **Database Management:** Uses SQLite for lightweight data storage (`university.db`).
- **Academic Tracking:** Includes modules for managing academic years, semesters, groups, subjects, grades, and teacher assignments.

## 🛠️ Tech Stack

- **Backend:** Python, Flask
- **Database:** SQLite, DB Browser for SQLite
- **Frontend:** HTML, CSS
